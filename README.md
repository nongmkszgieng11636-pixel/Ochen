# ОЧЕНЬ · мастерская авторского трикотажа

Сайт-каталог мастерской ОЧЕНЬ (Оксана, Балаково).

- `index.html`: структура страницы, тексты, контакты.
- `style.css`: оформление. Цвета: бордовый `#590916`, молочный `#f8f4ea`, почти чёрный `#201a1b`; шрифт Ochen Serif.
- `app.js`: модели каталога (массив `models` в начале файла), избранное, мерки, сообщения Оксане.
- `assets/`: фото (`имя.webp` для карточек, `имя-large.jpg` для увеличения), видео и шрифт.

Цена и состав модели задаются полями `price` и `composition` в `app.js`. Пустое поле показывается как «По запросу» и «Уточняется».
